Profile Builder
Web UI for generating Agama JSON profiles interactively. Fill in the form — get valid JSON instantly.
  • All 15 profile sections covered
  • Live JSON preview with syntax highlighting
  • Inline validation and warnings
  • Network, LVM, LUKS, Wi-Fi, NTP
  • Scripts (pre / post / init phases)
  • Copy or download the profile
  • Single HTML file — no server needed

Profile Validator
Command-line tool that checks an existing Agama JSON profile for errors and warnings.
  • JSON syntax & trailing comma detection
  • Required field validation
  • Wrong script property names
  • Bootstrap scripts in wrong phase
  • Unknown top-level keys
  • Python 3.6+ — zero dependencies
  • Exit code 0/1 for CI integration

Quick start — validator
curl -O https://raw.githubusercontent.com/rgeorgie/agama-syntax-checker/main/check-agama-profile.py
chmod +x check-agama-profile.py
./check-agama-profile.py my-profile.json
