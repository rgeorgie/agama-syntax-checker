📦 Product
Mandatory. Specifies which product to install and how to register it.
SLES supports standard and immutable modes.
Registration (SLE only)
Set to "" to skip SCC registration silently.
Use for RMT or custom SUSE registration servers.
Add-ons / Extensions
🔑 Root Authentication
Set authentication for the root user. At least one of password or SSH key must be defined (or define a first user instead).
Single key or multiple keys (one per line). Written to /root/.ssh/authorized_keys.
👤 First User (user)
Defines the first user account. Output in standard Agama "user": { ... } object format. Either user credentials or root credentials must be set for installation to succeed.
User Account
Written to /home/<userName>/.ssh/authorized_keys.
🌍 Localization
Locale, keyboard layout, and timezone. All fields optional — installer defaults used if omitted.
Run: localectl list-locales
Run: localectl list-keymaps
Both us(dvorak) and us-dvorak formats supported.
e.g. Europe/Berlin, America/New_York
🖥️ Hostname
Set the static and/or transient hostname of the installed system.
Persistent hostname stored in /etc/hostname. This is what you most likely want.
Temporary hostname set by the kernel — overridden by DHCP.
🌐 Network
Define network connections. Each connection maps to a NetworkManager connection profile.
📋 Software
Additional packages, patterns, and repositories on top of the product defaults.
Patterns
If you specify patterns, pre-selected patterns (e.g. selinux) will NOT be installed unless included. Use "Add Patterns" mode to keep defaults.
Find available patterns: zypper se --type pattern

Extra Repositories
🔧 Bootloader
Optional bootloader settings. Agama configures the bootloader automatically in most cases.
Seconds to wait before booting default. Must be positive.
💾 Storage
Disk layout configuration. Use Legacy AutoYaST for simple setups, or Native Agama format for full control.
Native Agama storage uses drives, volumeGroups, mdRaids, and boot sections. Use the JSON editor below for full control.
Native Storage JSON
Full native Agama storage schema. Supports drives, volumeGroups (LVM), mdRaids, encryption (LUKS2), filesystem types, sizes, search, and more.
🔒 Security
SSL certificates to trust during installation. Useful when using internal/mirrored repos with custom HTTPS certificates.
Trusted SSL Certificates
📜 Scripts
User scripts run at different points during installation.
Phase guide:
pre — before hardware analysis (enable multipath, tweak install media).
post — after install, in installer environment. chroot=true runs on installed system, but systemd is NOT active.
init — first boot of installed system. Fully operational systemd. Use this for registration/bootstrap scripts.
📁 Files
Deploy files to the installed system. Useful for config file snippets, sysctl.d entries, etc.
❓ Questions
Control how the installer handles interactive prompts during unattended installation.
Recommended: "auto" for fully unattended installs.
Automatic Answers (optional)
Pre-answer specific installer questions. Common use: auto-ignore unsigned packages or unknown GPG keys.
🔓 Access
Configure SSH and web console access on the installed system.
⏱ NTP
Force specific NTP sources. If defined, Agama uses these instead of defaults and copies config to installed system.
🚀 Kernel / PXE Boot Options Generator
Generate exact kernel command-line strings for Cobbler, Uyuni / SUSE Multi-Linux Manager, or PXELINUX / GRUB2 boot menus. Avoids common pitfalls like inst.auto=1, missing rd.live.image, or Cobbler's =~ boolean flag corruption.
